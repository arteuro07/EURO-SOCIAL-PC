# Décors réutilisables

- `LOC-QUARTIER` : rue principale du quartier.
- `LOC-BOUTIQUE` : commerce de proximité.
- `LOC-COIN-REPERE` : coin de rue de rendez-vous.

Ces décors sont des concepts, pas encore des modèles 3D. Lors de leur création, ajouter une fiche par décor avec les fichiers source, la version, les dimensions approximatives et les épisodes où il apparaît.
